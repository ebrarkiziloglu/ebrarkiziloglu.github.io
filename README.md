# ebrarkiziloglu.github.io

Static personal site (no build step). Files: `index.html`, `style.css`, `main.js`, `engine.js` (Turkish inflection engine), `cv.pdf`.

Deploy: create a public GitHub repo named exactly `ebrarkiziloglu.github.io`, push these files to `main`, then
Settings → Pages → Deploy from branch → `main` / root. Live at https://ebrarkiziloglu.github.io.

Preview locally: `python3 -m http.server 8000`
